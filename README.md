# 페이스 (PACE)

고등학생의 **탐구 주제 탐색 → 수행평가·탐구 일정 → 자료 조사·AI 질문 → 내 생각 정리**를 한곳에 연결하는 학습 웹서비스입니다.

## 실행

Node.js 22.13 이상이 필요합니다. 개발 시 24 LTS를 사용했습니다.

1. 이 폴더에서 `npm ci --include=dev --include=optional`을 실행합니다.
2. `.env.example`을 참고해 로컬 `.dev.vars`에 `GROQ_API_KEY`를 설정합니다. 키는 서버에서만 사용하며 Git에 올리지 않습니다.
3. `npm run dev -- --host 127.0.0.1 --port 4181`을 실행합니다.
4. 표시되는 로컬 주소를 엽니다. 개발 모드에서는 로컬 로그인 사용자를 제공합니다. 배포본은 ChatGPT 로그인을 사용합니다.

예약 알림 저장소까지 로컬에서 검사하려면 `npm run build` 후 `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_romantic_mauler.sql`로 초기 스키마를 적용하세요. 기존 데이터베이스에 같은 초기 SQL을 반복 적용하지 마세요.

## 구현한 흐름

- 활동을 등록하기 전, 관심사·교과·기간·도구와 제약을 입력해 탐구 후보 3가지를 제안받습니다. 추가 조건으로 다시 좁히고, 선택한 후보의 질문·방법·첫 할 일을 활동으로 옮깁니다.
- 수행평가·탐구 마감과 준비 시간을 입력하면 하루 가능 시간에 맞게 할 일을 나눕니다. 완료한 기록은 재계획 때 유지합니다. 준비 완료 목표일을 마감 전으로 정할 수 있고, 총 준비량·완료·남은 양·배정량·부족량의 계산 근거가 표시됩니다.
- 활동별 체크리스트, 내 생각 노트, AI 참고 노트, 관련 파일과 조사 출처를 보관합니다.
- PDF·PPTX·TXT에서 텍스트를 추출합니다. PDF 원문과 추출 결과를 확인하고 필요한 쪽을 AI 문자 인식한 뒤 직접 검토·수정할 수 있습니다. 구형 PPT는 PDF/PPTX로 변환해야 합니다.
- 과목별 AI 질문과 후속 대화, 자료로 만드는 일반 연습 문제와 선생님별 예상 문제를 분리합니다. 선생님·수업별로 기출과 이번 시험 수업 자료를 지정하면 기출에서 관찰한 출제 특징·근거·적용 방식을 정리하고 수업 자료 범위로 예상 문제를 만듭니다. 답안과 오답 메모도 자동 저장합니다.
- 실제 Crossref 검색 결과의 논문 제목·초록·DOI 링크를 활동에 저장합니다. AI의 조사 제안은 논문 본문을 읽은 결과와 구분합니다.
- AI 설명·문제·해설·참고 노트는 마크다운과 KaTeX로 표시합니다. 분수·루트·지수를 ASCII 문자식으로 대체하지 않습니다.
- 일정과 공부 기록은 이 브라우저의 IndexedDB에 저장합니다. JSON 백업·복원, 알람이 포함된 캘린더 파일 내보내기가 있습니다.

## AI 연결

텍스트 설명과 문제 생성은 Groq의 `openai/gpt-oss-120b`, 페이지 문자 인식은 `qwen/qwen3.8-27b`를 사용합니다. API 키는 서버 비공개 환경 변수에 설정합니다. 요청 전에 외부 AI로 보낼 내용에 대한 동의를 받습니다. 무료 한도 초과를 오류로 안내하며 유료 모델로 자동 전환하지 않습니다.

업로드 자료 전체를 학습시켜 모델을 바꾸는 방식이 아닙니다. 선택한 문서의 관련 텍스트를 찾아 질문에 함께 제공합니다. AI가 선택한 짧은 근거 번호를 서버가 실제 원문·자료 ID·쪽 번호로 연결합니다. 기출 특징에는 기출 근거, 선생님별 예상 문제에는 수업 자료 근거가 있어야 합니다. 근거 연결이나 형식이 누락되면 같은 무료 모델로 한 번 자동 재시도합니다. 읽을 수 없는 수식·문자 자료는 별도로 안내하며 임의의 내용을 근거로 사용하지 않습니다. 교사 성향은 실제 제공된 기출에서 관찰할 수 있는 문항 유형과 개념에 한정합니다.

## 검증

- `npm test`: 날짜·계획·백업·알림·시간표 비교·AI 입출력·출처 검증·마크다운·수식·탐구 주제 흐름 테스트.
- `npx tsc --noEmit`: 타입 검사.
- `npm run build`: 배포 빌드.
- 실제 Groq 키로 텍스트 질의와 공식 2026학년도 수능 수학의 텍스트 문항 9개를 검사했으며 해당 9개는 공식 정답과 일치했습니다. 전 과목 정확도를 입증하는 결과는 아닙니다.
- 스캔/수식 PDF 문자 인식은 실제 원문을 오인한 사례가 있었습니다. 자동으로 정답 근거로 확정하지 않고 원문 대조를 요구합니다.

## 미완료 및 제한

- 시간표는 TimeForSchool 공개 중계 API에서 출처를 명시해 조회합니다. 실제 고등학교 학급의 나이스 5일 시간표 실제 표시를 검증했습니다. 컴시간 조회 경로는 현재 upstream 오류로 실패하며, 나이스 자료를 컴시간 당일 변경 정보라고 표시하지 않습니다. 학교/학급/주/출처가 같을 때만 변경을 비교합니다. 화면을 보는 동안 5분 확인을 선택할 수 있고, 닫힌 상태의 시간표 감시는 미완료입니다.
- 서버 알람의 사용자별 저장/취소, VAPID Web Push 암호화·발송 경로를 구현했습니다. 정기 실행이 연결되지 않아 예약 버튼은 비활성화됩니다. Sites 예약 도구의 1시간 최소 간격 제한으로 5분 예약 생성이 실패했으며, 실제 기기 수신도 확인하지 못했습니다. 이 부분을 완성된 기능으로 간주하지 마세요.
- 현재 브라우저를 열어 둔 동안의 마감 확인과 캘린더 알람 내보내기를 제공합니다. 실제 운영체제 알림 표시는 기기의 권한과 설정에 따라 확인이 필요합니다.
- 다른 기기와 자동 동기화되지 않습니다. JSON 백업은 원본 파일을 포함하지 않으므로 원본은 별도로 보관해야 합니다.
- 수식·그림·표·스캔 문서와 AI 답변에는 오류가 있을 수 있습니다. 공식 원문·정답과 대조해야 합니다.
- 직접 재생되는 정확한 영상 자료 추천은 후순위 개발 항목입니다.
- 상용 운영에 필요한 다중 사용자 저장, 서비스 운영 정책, 부하·장애 대응은 별도 검증이 필요합니다.
